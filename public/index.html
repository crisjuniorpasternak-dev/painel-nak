Como os números são calculados
  • Fonte: funil [Vendas] [Omie] do CRM DataCrazy, lido pela API do CRM de hora em hora no horário comercial e por completo toda madrugada. A etapa Duplicado fica de fora.
  • Produtos: itens de cada negócio faturado como estão no CRM.
  • A data de cada negócio é a da última mudança de etapa (o CRM não informa a data de criação). Para pedidos faturados, é o dia do faturamento.
  • Faturado: etapa Faturado. Em aberto: Orçamento Gerado, Separação de Estoque e Aguardando Faturamento. Taxa de fechamento: faturados ÷ (faturados + em aberto).
  • A variação compara com o período anterior de mesmo tamanho (num mês, com o mês anterior).
  • Curva ABC: clientes do maior para o menor faturado; A soma os primeiros 80%, B os 15% seguintes e C os últimos 5%. Clientes agrupados pelo nome no CRM.
  • Recompra a cada: dias entre a primeira e a última compra divididos pelo número de intervalos entre compras.
